Storage boundary

Selected: IndexedDB behind BlogService. It tolerates uploaded image data better than localStorage and keeps the UI independent from the future API.

Production migration replaces the repository, not the page components.

Admin access

Selected: demo-only credentials with a one-click autofill action and a session-scoped browser flag.

The login page and collection point explicitly warn that this is not production authentication.

Rich-text editor

Selected: Tiptap’s MIT-licensed core instead of the APWU TinyMCE setup, whose current self-hosted release requires GPLv2+ compliance or a commercial license.

Toolbar scope: headings, emphasis, lists, quote, rule, links, undo/redo, and locally persisted images.

Search model

Selected: quantized Xenova/all-MiniLM-L6-v2, served from this site. The Apache-2.0 model runs in-browser through Transformers.js.

It warms during idle time, uses WebGPU when suitable, falls back to WASM, and never blocks keyword/fuzzy search.
